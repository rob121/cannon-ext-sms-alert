Setup checklist

Configure Twilio, create a list keyword, then add a Cannon route so inbound SMS can reach this extension.

  1. 1
    Configure Twilio

    Open Twilio Settings and enter SID, auth token, and default from-number. Use the test pair while Development Mode is on.

  2. 2
    Add a from-number

    Under Numbers, add your Twilio number in E.164 (for example +15551234567) and assign it when you create a list.

  3. 3
    Create a list

    Add a list with a unique keyword. Subscribers text that keyword to join; reply remove to leave.

  4. 4
    Create the webhook route in Cannon

    This path is not mounted automatically. Add a route under System → Routes (or Add Route) with these values:

    Name
    SMS Alert webhook (any label)
    Path
    {{.WebhookPath}}
    Type
    Extension Endpoint
    Extension
    SMS Alerts
    Endpoint
    Twilio Inbound Webhook

    Keep the path under /webhooks/ so CSRF is skipped for Twilio’s POST. Until the route exists, the URL returns 404.

  5. 5
    Point Twilio at the route

    In the Twilio Console for your number, set the messaging webhook to your public site URL plus {{.WebhookPath}}, method HTTP POST.

    A browser GET after the route exists should respond with “POST required”. Signatures are checked with the active auth token (test or live from Development Mode).
